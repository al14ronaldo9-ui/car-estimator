# Car Estimator

سامانه برآورد خسارت خودرو با تشخیص آسیب در مرورگر، برآورد هزینه و دستیار هوش مصنوعی.

## ساختار

- `index.html` — صفحه اصلی و مسیر سریع برآورد
- `analyze.html` — صفحه کامل تحلیل تصویر و برآورد هزینه
- `chat.html` — دستیار، انجمن و گفتگوی عمومی
- `account.html` — حساب کاربری
- `admin.html` — پنل مدیریت
- `expert.html` — پنل کارشناس
- `login.html` / `signup.html` — احراز هویت
- `static/best.onnx` — مدل تشخیص آسیب
- `supabase/functions/ai-car-analysis/index.ts` — واسط سرور برای تحلیل تکمیلی AI
- `premium-ui.css` / `app-nav.js` — اجزای مشترک رابط کاربری

## منطق برآورد قیمت

برآورد هزینه بر اساس نوع آسیب، گستردگی آسیب، مدل خودرو و سال ساخت انجام می‌شود. خروجی همیشه به‌صورت بازه نمایش داده می‌شود و قیمت قطعی تعمیرگاه نیست.

قیمت‌های پایه برای سال ۱۴۰۵ با تکیه بر نرخ‌های منتشرشده خدمات بدنه و قیمت‌های بازار قطعات تنظیم شده‌اند و باید در صورت تغییر محسوس بازار به‌روزرسانی شوند.

## مدل ONNX

مدل در مرورگر با ONNX Runtime Web و WebAssembly اجرا می‌شود. کش مدل با نسخه `v3` و query version کنترل می‌شود تا نسخه قدیمی مدل در مرورگر باقی نماند.

## توسعه

پروژه بدون بک‌اند برای تشخیص اصلی قابل اجراست؛ فقط برای قابلیت تحلیل تکمیلی AI به Supabase Function نیاز دارد.

## تغییرات نسخه پاک‌سازی‌شده
- تاریخچه دستیار فقط در حافظه همان صفحه نگه داشته می‌شود و با خروج از صفحه پاک می‌شود؛ پیام‌های دستیار در جدول عمومی ذخیره نمی‌شوند.
- چت عمومی با cron روزانه در ساعت ۰۰:۰۰ به وقت ایران پاک می‌شود. فایل `supabase/migrations/20260830_public_messages_cleanup.sql` را یک‌بار در SQL Editor سوپابیس اجرا کنید.
- صفحه لودینگ به تصویر برداری آبی/مشکی جدید تغییر کرده و چراغ‌ها نسبت به تصویر جدید تراز شده‌اند.
- برای مدل خسارت، آستانه اطمینان و کیفیت ماسک سخت‌گیرانه‌تر شده تا false-positive روی اشیای غیرخودرو کمتر شود.

> مدل `static/best.onnx` یک مدل سفارشی YOLOv8-seg برای آسیب خودرو است و کلاس «خودرو» مستقل ندارد؛ بنابراین گیت فعلی false-positive را کاهش می‌دهد، اما جایگزین یک vehicle-detector جداگانه نیست. برای افزودن detector دوم باید وزن ONNX آن به پروژه اضافه شود.

## مدل‌های پیشنهادی جدید

- **ماسک آفلاین فعلی:** `static/best.onnx` فعلاً نگه داشته شده تا نسخه مرورگر پایدار بماند.
- **گزینه قوی‌تر برای تعویض ماسک:** CarDD YOLOv8s v2 از `abdullahg7/cardd-yolov8s`؛ مدل سگمنتیشن با mAP50 ماسک 75.90% و حجم حدود 22.5MB. فایل منتشرشده وزن PyTorch است و قبل از جایگزینی باید به ONNX سازگار با onnxruntime-web تبدیل و روی مجموعه تست پروژه اعتبارسنجی شود.
- **گزینه آنلاین ماسک:** Roboflow `car-damage-v5-wdqin/1` با 4 کلاس و mAP@50 گزارش‌شده 90.7% در صفحه مدل. مسیر Supabase برای استفاده از آن آماده شده است؛ فقط `ROBOFLOW_API_KEY` باید در Secrets تنظیم شود. مدل پیش‌فرض این مسیر `car-damage-v5-wdqin/1` است.
- **تحلیل تخصصی تصویری:** مسیر آنلاین Hugging Face فعلی از مدل بینایی `zai-org/GLM-4.5V` استفاده می‌کند و با پرامپت تخصصی خودرو محدود شده است.
- **مدل تخصصی قابل بررسی برای مرحله بعد:** `Kakyoin03/car-damage-assessment-llama-vision`، فاین‌تیون‌شده برای ارزیابی حرفه‌ای خسارت خودرو. این مدل حدود 11B پارامتر دارد و برای اجرای مستقیم نیازمند زیرساخت GPU است، بنابراین برای اجرای مستقیم روی گوشی مناسب نیست.

### نکته مهم
برای جلوگیری از تشخیص لیوان یا تصویر نامرتبط به‌عنوان خسارت، قبل از اجرای مدل ماسک یک مرحله اعتبارسنجی «آیا تصویر واقعاً خودرو دارد؟» اجرا می‌شود. اگر تصویر خودرو نباشد، تحلیل محلی و برآورد قیمت متوقف می‌شود.
